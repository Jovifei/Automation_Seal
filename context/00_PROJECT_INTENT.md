# 项目初衷

## 原始目标

利用家中电脑、Codex和本地自动化工具，在无人持续盯守的情况下完成合法的市场调研、产品设计、代码开发、测试、文档和内容草稿工作，最终形成可以在闲鱼等平台销售的原创数字产品与专业服务。

## 两条业务线

1. **嵌入式工程产品**：Modbus、FreeRTOS、STM32/GD32、4G/MQTT、OTA、HardFault等工具、模板和诊断服务。
2. **摄影原创产品**：原创XMP预设、练习RAW、机位指南、调色视频和照片点评。

## 商业原则

- 卖“验证过的结果”，不卖“网络收集的资料数量”。
- 优先工具包、可编译工程、测试报告、兼容矩阵和问题诊断。
- 内容平台建立信任，闲鱼承接经过批准的交易。
- 从低价入口产品逐步升级到诊断、适配和定制服务。

## 不属于本项目的内容

- 盗版课程、破解软件、共享账号、激活码；
- 未经授权的预设、字体、模板、照片和源码；
- 公司、客户或雇主代码；
- 自动养号、批量私信、验证码绕过和风控对抗；
- 无人审核的报价、承诺、交付、退款和支付。

## 成功定义

系统能够稳定地：

1. 发现并记录有证据的用户问题；
2. 将问题转成PRD、任务和验收标准；
3. 自动完成可测试的产品构建；
4. 生成版权清单、说明文档和内容草稿；
5. 经过人工哈希批准后形成可交付包；
6. 保持闲鱼账号、客户数据和交易动作在用户控制之下。
