# 执行摘要
本项目采用“入口产品—标准产品—服务产品—定制项目”的价值阶梯。免费内容用于证明能力，低价产品验证付费，中价产品形成可重复收入，服务用于提高客单价并收集需求。所有产品必须可追溯权利来源、版本和交付记录。

# 6. 单位经济模型
首轮不估算虚假的市场规模，重点确认每单贡献毛利和主理人时间。
| 指标 | 定义 | 目标/警戒线 |
| --- | --- | --- |
| 客单价 AOV | 实收收入/订单数 | 入口产品≥29；标准产品≥79 |
| 变动成本 | 支付/平台费+素材授权+云存储+售后时间成本 | 数字产品<售价30% |
| 贡献毛利 | 收入-变动成本 | 连续4周为正 |
| 售后时间 | 咨询、兼容、退款处理分钟数/单 | 标准产品≤20分钟 |
| 内容获客成本 | 外包、设备、投流支出/付费客户 | 先以自然流量验证；付费投流需回收 |
| 退款/争议率 | 退款或平台纠纷订单/总订单 | <10%；>15%立即暂停 |

# 7. 版本与授权模式
数字产品采用个人使用授权，默认不得二次分发、转售、公开上传或用于制作同类资源包。
嵌入式源码明确哪些部分为原创、开源组件和第三方依赖，并附许可证。
摄影RAW只授予学习用途；是否允许发布练习成片必须单独说明。
重大版本升级可收费；缺陷修复和承诺范围内的兼容修正免费。
不承诺“永久更新”，改为写明版本支持期限和更新策略。

# 9. 商业模式验证顺序
先卖服务：确认用户愿意为哪些结果付费，积累原话和失败案例。
把重复问题做成入口产品和标准产品。
用内容解释产品解决的问题，不直接做低质量广告。
产品累计10-20单后再投入更完整视频、自动化和投流。
连续4周数据不达标时，先改变问题和目标用户，不盲目扩平台。
