# 1. 产品背景
用户能找到大量苏州照片和通用预设，但很难把“天气、时间、机位、焦段、曝光和后期”连成完整流程。本产品使用原创照片和真实拍摄经验，提供可复现的拍摄与调色路径。
# 2. 产品目标与非目标
| 类型 | 内容 |
| --- | --- |
| 目标 | 帮助用户在计划、拍摄和后期三个阶段降低试错；在30分钟内完成预设安装和第一张练习RAW调色。 |
| 业务目标 | 上线30天获得10个订单；教程完成率>60%；满意度≥4.5/5；退款<10%。 |
| 非目标 | 不保证天气、晚霞或固定机位永久开放；不承诺一键适配所有相机和照片；不提供他人预设或未经授权素材。 |

# 3. 目标用户

# 6. 内容标准
所有示例照片和RAW由项目方原创，保留原始文件、拍摄日期和导出记录。
前后对比不得通过替换天空、合成素材或隐藏关键步骤制造误导；如使用合成必须明确标注。
机位信息应包含“信息可能变化”提示，并设置最近核验日期。
预设只作为起点，教程必须说明曝光和白平衡调整，而不是宣传“一键出片”。
涉及人员、建筑内部、无人机或商业场地时单独确认拍摄和发布权限。

# 8. 用户流程
用户从小红书/抖音看到真实前后对比和拍摄过程。
在商品页确认适用软件、相机差异、机位更新时间和授权范围。
购买后下载版本化压缩包并阅读QuickStart。
导入预设→打开练习RAW→跟随视频→保存自己的调整。
计划拍摄时使用机位指南和天气清单；遇到问题按FAQ处理。
需要逐张点评时购买独立服务，不把标准产品售后变成无限修图。
