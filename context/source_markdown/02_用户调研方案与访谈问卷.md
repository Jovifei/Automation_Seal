# 用户调研方案与访谈问卷
在开发前验证问题、付费意愿与交付形式

| 项目 | Jovi 嵌入式与摄影数字产品项目 |
| --- | --- |
| 文档版本 | V1.0 |
| 编制日期 | 2026年7月11日 |
| 文档状态 | 可执行草案 / 待市场验证 |

用途：用于个人数字产品项目的立项、验证、开发、上线与复盘。

# 1. 调研目标
确认用户最近一次真实问题，而不是询问抽象兴趣。
识别用户目前如何解决、花费多少时间/金钱、最不满意什么。
验证产品内容、交付格式、适用芯片/软件版本、价格和售后预期。
发现版权、隐私、远程协助和退款方面的顾虑。
# 2. 样本设计
| 细分 | 访谈人数 | 问卷人数 | 招募渠道 | 合格标准 |
| --- | --- | --- | --- | --- |
| 嵌入式初学者 | 5-8 | 20+ | B站评论、技术群、同事朋友 | 近3个月学习STM32/GD32/FreeRTOS |
| 嵌入式在职工程师 | 5-8 | 20+ | 技术社区、朋友转介绍 | 近3个月处理过通信/RTOS/4G问题 |
| 苏州城市风光摄影用户 | 5-8 | 20+ | 小红书、摄影群、朋友 | 近6个月拍过城市风光或计划来苏州 |
| 摄影调色学习者 | 5-8 | 20+ | 小红书/抖音评论 | 使用LR/ACR并愿意练习RAW |

| 最小样本：每条产品线至少完成10次有效访谈；在观点开始重复之前不要停止。问卷用于验证比例，不替代访谈。 |
| --- |

# 3. 招募话术
嵌入式招募：我正在研究工程师在Modbus/FreeRTOS/4G通信调试中的真实困难，不推销产品。想用20分钟了解你最近一次问题和解决过程，访谈内容仅用于产品设计，可匿名记录。
摄影招募：我正在设计一套苏州城市风光拍摄与调色工具，希望了解你在机位、天气、参数和后期方面的真实困难。访谈约20分钟，不推销产品，可匿名。
# 4. 访谈规则
先问过去发生的事情，再问未来意愿；“你上次怎么做”比“你会不会买”更可靠。
不介绍产品前先完成问题访谈，避免诱导。
对价格使用阶梯测试：免费→19→59→199元，询问拒绝原因和需要增加什么。
记录原话、时间成本、替代方案、失败后果和是否已经付费。
未经许可不保存代码、照片、屏幕录制、公司名称或个人联系方式。
# 5. 嵌入式用户访谈提纲
请讲讲最近一次让你卡住超过2小时的嵌入式问题。发生在什么项目和阶段？
你最先去哪里找答案？用了哪些关键词、教程、官方文档或开源项目？
最后如何解决？总共花了多少时间？是否影响交付、加班或购买硬件？
现有资料最让你不满意的地方是什么：不能编译、版本不一致、解释不清、缺测试、无人答疑，还是其他？
你是否购买过课程、代码、咨询或远程调试？价格、结果和不满意点是什么？
对于一个Modbus诊断工具包，你最想包含哪些内容？哪些内容没有价值？
你使用哪些芯片、IDE、RTOS、编译器和调试工具？版本变化是否经常造成问题？
如果产品价格为19/59/199元，你分别期待得到什么？什么情况下绝不会买？
你能否接受只覆盖明确芯片和版本？希望免费支持多久？
你最担心卖家看到哪些代码或数据？你需要怎样的保密承诺？
# 6. 摄影用户访谈提纲
请讲讲最近一次城市风光拍摄。你如何决定地点、时间和天气？
拍摄中最容易失败的环节是什么：机位、交通、构图、曝光、滤镜、天气还是后期？
你通常从哪里找机位和调色教程？哪些信息不准确或不够具体？
你买过预设、机位指南、课程或照片点评吗？为什么买/不买？
使用预设后最常见的问题是什么：颜色不一致、肤色/天空异常、不同相机不兼容、不会微调？
对于金鸡湖工具包，你更看重预设、RAW练习、机位、时间、停车、天气、焦段还是完整视频？
如果价格为19/59/129元，你分别期待得到什么？
你愿意提交RAW给他人点评吗？对隐私、水印和作品使用有什么要求？
什么结果会让你主动推荐给朋友？
# 7. 在线问卷模板
| 模块 | 问题内容 | 题型 |
| --- | --- | --- |
| 筛选 | 你的身份/经验年限/最近一次相关活动时间 | 单选 |
| 问题频率 | 过去3个月遇到相关问题的次数 | 0/1/2-3/4+ |
| 损失程度 | 最近一次问题耗时或失败成本 | 区间 |
| 替代方案 | 官方文档/B站/论坛/GitHub/朋友/付费服务 | 多选 |
| 付费历史 | 是否买过课程/源码/预设/咨询；最高单笔金额 | 区间 |
| 功能排序 | 从候选功能中选最重要3项 | 排序 |
| 交付偏好 | PDF/视频/源码/工具/群答疑/一对一 | 多选 |
| 价格敏感 | 价格过低不可信/合适/偏高/无法接受 | 四点价格法 |
| 购买障碍 | 版权、效果、兼容、售后、退款、隐私、其他 | 多选+开放 |
| 联系方式 | 可选，愿意参加内测 | 可选 |

# 9. 决策门槛
| 指标 | 继续开发 | 调整 | 停止/换方向 |
| --- | --- | --- | --- |
| 真实痛点确认 | ≥60%访谈者近3个月遇到 | 40%-59% | <40% |
| 已有付费/强时间成本 | ≥40% | 20%-39% | <20% |
| 产品概念明确吸引 | ≥50%愿意内测 | 30%-49% | <30% |
| 预售/服务付费 | 30天≥5单 | 1-4单 | 0单且无明确改善方向 |
| 售后可控 | 平均≤20分钟/单 | 20-45分钟 | >45分钟且无法标准化 |

# 10. 调研输出
问题优先级列表：频率×损失×付费证据。
用户原话库：用于商品标题、详情页和内容脚本。
功能删减清单：不重要或容易造成售后的功能。
兼容矩阵：芯片、IDE、软件和相机版本。
价格实验结果：接受区间、拒绝原因和需增加的价值。
