# 90天执行计划与SOP
从验证需求到稳定交付的周级行动方案

| 项目 | Jovi 嵌入式与摄影数字产品项目 |
| --- | --- |
| 文档版本 | V1.0 |
| 编制日期 | 2026年7月11日 |
| 文档状态 | 可执行草案 / 待市场验证 |

用途：用于个人数字产品项目的立项、验证、开发、上线与复盘。

# 1. 90天目标
| 结果 | 目标 |
| --- | --- |
| 用户证据 | ≥20次有效访谈、≥40份合格问卷、30个竞品样本 |
| 产品 | E01与P01两个MVP正式发布；E02与P02两个服务可交付 |
| 成交 | 累计10-30个真实付费订单，形成价格和拒绝原因记录 |
| 运营 | 建立每周内容节奏、商品页、客服、交付和复盘SOP |
| 合规 | 每个SKU有权利登记、许可证、版本和交付证据 |

# 2. 周计划
| 周 | 主题 | 关键任务 | 交付物 |
| --- | --- | --- | --- |
| W1 | 立项与红线 | 整理个人可用资产；建立权利登记；确定两条线的访谈对象 | 文档包确认、资产清单 |
| W2 | 问题访谈 | 完成嵌入式5次、摄影5次访谈；开始竞品抽样 | 访谈记录、问题排名 |
| W3 | 付费验证 | 完成剩余访谈；发布服务测试页/预售意向 | Go/No-Go结论 |
| W4 | MVP设计 | 冻结E01/P01范围、兼容、验收和价格三档 | PRD冻结、Backlog |
| W5 | 核心制作 | 开发帧分析器/模板；整理RAW/预设/机位 | Alpha |
| W6 | 测试与文档 | 自动测试、跨环境测试、教程和授权 | Beta |
| W7 | 内测 | 各5名用户内测；记录完成率和问题 | RC版本 |
| W8 | 上线准备 | 商品页、内容、FAQ、交付演练和风控检查 | 正式上架 |
| W9 | 首轮成交 | 人工服务和售后，记录所有问题 | 首周复盘 |
| W10 | 优化转化 | 优化标题、首屏、价格和FAQ | A/B实验结果 |
| W11 | 降低售后 | 把重复问题转为自检和产品修复 | 支持时间下降 |
| W12 | 复购与第二SKU | 升级版/新场景方案，不急于扩平台 | 第二阶段路线 |
| W13 | 季度复盘 | 财务、产品、渠道、合规和时间复盘 | 继续/调整/停止决策 |

# 3. 每日与每周SOP
## 3.1 每日30-60分钟
检查咨询和订单，只处理明确范围；重要承诺写回平台。
记录一条用户原话、一个阻塞或一个可复用问题。
开发/内容只推进当天最重要的一项，不同时开多个大任务。
备份工作目录，客户文件不进入个人素材库。
## 3.2 每周2小时复盘
更新看板KPI和收入成本。
复盘本周订单、退款、售后时间和缺陷。
检查内容到咨询、咨询到支付的瓶颈。
更新风险登记和版权来源。
确定下周唯一核心实验和停止事项。
# 4. 竞品抽样SOP
每条产品线采样15个商品/内容，共30个；记录日期和截图，不依赖搜索结果数量。
字段：平台、关键词、标题、承诺、交付、价格、销量/评价可见信号、更新时间、版权风险、差评点。
不要复制对方文案、封面或资源；只提炼用户问题和市场结构。
输出：高频关键词、价格带、未满足需求、不可进入的低价/侵权区域。
# 5. 开发SOP
| 步骤 | 嵌入式 | 摄影 | 完成证据 |
| --- | --- | --- | --- |
| 需求冻结 | 芯片/IDE/功能码/支持范围 | 场景/相机/软件/机位 | PRD版本号 |
| 资产登记 | 原创代码/依赖/许可证 | RAW/照片/字体/音乐/地图 | 权利登记表 |
| 制作 | 模块化、测试优先 | 非破坏性编辑、过程录制 | 源文件与提交记录 |
| 测试 | 干净环境、自动/硬件测试 | 跨相机、跨软件、内测复现 | 测试报告 |
| 打包 | 版本、哈希、许可证、变更说明 | 预设、RAW、指南、授权、变更 | Release包 |
| 交付演练 | 按买家视角从零安装 | 按买家视角导入和跟练 | 演练记录 |

# 6. 决策规则
| 信号 | 动作 |
| --- | --- |
| 有咨询但不付费 | 检查信任、兼容、交付和价格；做一次单变量实验 |
| 有付费但退款高 | 立即暂停扩量，修正承诺、质量和适用范围 |
| 播放高但无精准咨询 | 内容过泛；改为具体问题、目标用户和结果 |
| 售后时间高 | 删功能、缩范围、增加自检、把定制变成独立服务 |
| 用户愿意付费服务但不买产品 | 先做5-10单服务，提炼重复问题后再产品化 |
| 存在版权不确定 | 不上架，直到获得授权或重新制作 |

# 7. 异常处理SOP
| 事件 | 立即动作 | 后续 |
| --- | --- | --- |
| 平台警告/下架 | 停止相似发布，保存通知和商品版本 | 核查规则、整改文案/类目/交付，不绕过审核 |
| 客户投诉侵权 | 暂停销售和传播，保全来源证据 | 核验权利，必要时下架/退款/咨询专业意见 |
| 客户代码泄露疑虑 | 停止处理并确认文件范围 | 删除无关文件、提供处理记录、改进隔离 |
| P0缺陷 | 暂停交付，通知已购买用户 | 发布修复、变更说明和补救方案 |
| 账号/支付异常 | 不点击陌生链接，不提供验证码 | 只用官方入口和客服处理 |

# 8. 90天结束评审
| 维度 | 继续条件 | 调整/停止条件 |
| --- | --- | --- |
| 需求 | 有重复痛点和付费证据 | 只有泛兴趣，无真实成本 |
| 产品 | 完成率、满意度和缺陷可控 | 无法标准化或承诺长期不稳定 |
| 渠道 | 至少一个渠道持续带来精准咨询 | 所有渠道均只有低质量流量 |
| 财务 | 贡献毛利为正，时间回报改善 | 售后/定制长期吞噬收入 |
| 合规 | 权利、平台和隐私风险可控 | 核心产品依赖无法授权资源 |
