# 1. 核心原则
能下载、能购买、能使用，不等于能复制、转售或公开传播。
数字商品发布前必须回答：谁创作、谁拥有、授权范围、是否允许商业使用、是否要求署名/开源、是否属于职务作品。
来源不清即不发布；不能用“网上都有”“别人也在卖”作为合规依据。
商品描述必须如实，平台交易记录、版本、交付内容和售后范围可追溯。
# 2. 权利分类矩阵
| 类别 | 是否可售 | 必要证据 | 注意 |
| --- | --- | --- | --- |
| 本人业余时间独立创作 | 通常可 | 源文件、提交记录、拍摄原片、创作日期 | 排除雇主设备/机密/本职任务 |
| 任职期间开发的代码/文档 | 高风险 | 劳动合同、项目约定、公司书面许可 | 可能属于职务软件 [S14] |
| 客户项目/日志/原理图 | 默认不可 | 客户明确书面授权与脱敏范围 | 保密、商业秘密和个人信息风险 |
| 开源代码 | 视许可证 | 仓库、版本、许可证、修改清单 | MIT/Apache/GPL等义务不同 |
| 购买的网课/电子书/插件 | 默认不可转售复制件 | 明确的商业转售授权 | 个人使用许可不等于发行权 |
| 商业软件/账号/激活码 | 通常不可擅自转售 | 厂商经销/转让许可 | 禁止破解、共享和绕授权 |
| 原创照片/预设/RAW | 可 | 原片、工程文件、人物/场地授权（如需） | 明确买家使用许可 |
| 公共领域/官方免费资料 | 视具体条款 | 官方来源、条款和使用日期 | 免费不一定允许再分发 |

# 3. 明确禁止的商品
未经授权复制的付费网课、电子书、题库、PPT、源码和网盘合集。
破解软件、补丁、激活工具、盗版插件、共享账号、批量许可证。
从公司、客户或同事处获得的内部代码、原理图、文档、密钥和数据。
他人的Lightroom预设、LUT、字体、照片、RAW、音乐和模板合集。
宣称可以绕过平台风控、自动养号、刷量、虚假评价或批量私信的工具和服务。
# 4. 开源组件审查
| 检查项 | 问题 | 记录 |
| --- | --- | --- |
| 许可证识别 | 仓库根目录和依赖中有哪些许可证？ | 名称、版本、URL |
| 商业使用 | 是否允许销售包含该组件的产品？ | 允许/限制/不确定 |
| 分发义务 | 是否必须保留版权声明、提供源码或修改说明？ | 具体动作 |
| 专利/商标 | 是否有专利授权或商标使用限制？ | 声明 |
| 依赖传递 | 间接依赖是否有更强义务？ | 依赖清单 |
| 替代方案 | 不兼容时能否替换或重写？ | 决策 |

# 5. 软件与课程的正确产品化方式
| 不要卖 | 可以卖 |
| --- | --- |
| 软件安装包、破解文件、激活码、账号 | 官方软件下载和安装配置教程、环境排错、正版采购指引 |
| 他人课程录像/课件合集 | 自己录制的课程、基于公开事实制作的原创讲解和案例 |
| 开源仓库原样打包冒充原创 | 按许可证合规集成，并提供移植、测试、文档和增值服务 |
| 他人预设/RAW合集 | 自己创作的预设、RAW、调色流程和授权文件 |

# 6. 客户数据与隐私
只收集完成任务所需的最小文件；优先要求最小复现而非完整工程。
每个客户建立独立目录和Git仓库；禁止把客户代码用于其他订单、模型训练或公开案例。
日志中删除Token、密码、IMEI、手机号、服务器地址和个人信息。
订单结束后按约定删除或归档；删除应包含临时文件、压缩包、云盘和备份。
公开案例必须重新构造或取得书面授权，不能只改项目名称。
# 7. 平台与消费者责任
闲鱼协议要求不侵害他人知识产权，并对经营性卖家规定如实描述和相应买家保障义务 [S10][S11]。平台的具体类目、数字商品和服务规则可能变化，应在发布当天核查。
不诱导站外支付，不通过链接索要验证码或账号密码。
商品页写清数字内容、服务范围、兼容、交付和退款条件。
保存交付证据：订单、聊天确认、文件清单、版本、哈希、下载或发送记录。
不可用“售出不退”代替法定和平台责任；出现重大缺陷主动补救。
持续经营达到经营者特征后，应关注主体登记、税务、发票和消费者权益义务。
# 8. AI与自动化风险控制
| 环节 | 允许 | 控制措施 |
| --- | --- | --- |
| 内容草拟 | 允许 | 检查事实、版权、夸大表述和平台敏感词 |
| 代码生成 | 允许 | 代码审查、测试、许可证扫描，不直接交付未验证代码 |
| 账号发布 | 人工确认 | 不绕验证码、不批量铺货、不伪装设备 |
| 客户回复 | 草稿辅助 | 承诺、价格、交期和退款必须人工发送 |
| 文件交付 | 人工确认 | 白名单打包、恶意文件扫描、客户隔离 |
| 删除/退款/支付 | 禁止自动 | 仅人工在官方平台执行 |

| 许可证 | 第三方组件的许可证和声明已附在产品中 | □ |
| 商品描述 | 适用范围、版本、限制、交付、售后和退款写清楚 | □ |
