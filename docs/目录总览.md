## 6. 为什么不物理移动旧文件

历史脚本、manifest、context、Prompt 和 audit 可能硬引用这些路径。文档治理采用：

- 保留路径；
- 重写仍属于 Living 的 Markdown；
- 用 status/index 标记已完成或历史；
- 不改冻结审计证据。

这样既保持审计可追溯，也避免新 Agent 误读。

## 7. 新增文档规范

推荐：
- 当前状态：`CURRENT_*`
- 当前执行计划：`C4_*` 或之后阶段号
- 独立审计：`*_INDEPENDENT_AUDIT_*`
- 历史迁移说明：放在 `HISTORICAL_DOCUMENT_STATUS.md`

任何新计划必须写：
- 状态（CURRENT / CANDIDATE / COMPLETED / HISTORICAL）；
- 前置 Gate；
- 成功停止点；
- 是否 Human Decision；
- real-action flags 边界。
