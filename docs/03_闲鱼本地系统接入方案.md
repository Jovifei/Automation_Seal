# 1. 接入决策

选择将`E:\project\xianyu-auto-reply`作为独立执行适配器，不平行开发第二套后台，不合并源码和数据库，不让Jovi直接写闲鱼SQLite。

# 2. 已知能力

上游项目基于FastAPI、SQLite、Playwright/DrissionPage和Docker Compose，具备多账号、关键词回复、AI回复、自动发货、商品、订单、日志和健康检查等能力。

本地实际版本、修改和配置只能由X0审计确认。

# 3. 上游基线风险

公开Compose曾出现：

- 9000、5900和6080非本机限定；
- root容器和整个源码读写挂载；
- 默认管理员密码和JWT示例；
- 自动回复和发货默认开启；
- VNC、远程滑块或后备验证能力；
- `latest`镜像。

这些是上游基线，不等于本地事实。

# 4. X0隐私审计

X0允许：

- HEAD、分支、工作区状态数量和状态码；
- 严格短版本号；
- Compose风险布尔值、端口、镜像和环境变量名；
- 容器状态、健康和OpenAPI路径/方法。

X0不允许：

- 输出Git变更路径；
- 打开、哈希或列出SQLite文件名；
- 读取Cookie、买家消息、卡密和Profile；
- 输出配置值；
- 启停容器或调用写接口。

# 5. X0-X4阶段

| 阶段 | 允许 | 禁止 | 退出条件 |
|---|---|---|---|
| X0 | 脱敏只读事实 | 修改和秘密内容 | 审计报告 |
| X1 | Jovi目录中的并行加固提案 | 覆盖或重启闲鱼工程 | 提案SHA256 |
| X2 | 虚构商品、消息、订单和空交付 | 真实账号和真实写动作 | 正负向测试通过 |
| X3 | 固定回复候选，用户手工启用 | 生成式AI直接发送 | 小范围观察和停用验证 |
| X4 | 单个原创SKU，用户手工启用 | 权利不明和批量资源 | 幂等、退款和回滚验证 |

# 6. 文件契约

候选包包含：

```text
bundle.json
listing_draft.md
reply_rules.json
delivery_catalog.json
rights_evidence/
test_report.md
manifest.sha256.json
package.sha256.txt
```

外部动作必须全部为false，批准回执与候选包分离。任何文件变化、缺失或新增未列文件都会使批准失效。

# 7. AI回复策略

只允许支持范围、所需资料、工作时间、购买前须知和固定FAQ候选。报价、议价、工期、投诉、退款、争议、高风险问题和站外联系必须转人工。

X3前必须通过Promptfoo合成评测。

# 9. 风控与紧急停止

本工程不实现验证码、滑块、人脸、设备指纹或平台风控绕过。出现验证时由用户按正常平台流程处理。

发生误回复、错误发货、隐私或账号异常时：用户先关闭Web后台开关，必要时停止容器，保留脱敏现场，不清理数据库、日志或浏览器Profile，完成根因分析后再恢复。
