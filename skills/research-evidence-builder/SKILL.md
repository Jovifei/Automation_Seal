# Research Evidence Builder

## Tool selection

- Use ordinary file reading/search for small, text-first source sets.
- Use Docling when layout, tables, equations, scans, Office documents, or local conversion materially improve extraction.
- Use PaperQA2 when the question requires multi-paper scientific evidence, citation-aware retrieval, or contradiction analysis.

## Workflow

1. State the research question, decision, inclusion criteria, time window, and evidence hierarchy.
2. Create a source registry with title, author/owner, URL/path, date, access status, license, and checksum where local.
3. Convert only documents the user has rights to process.
4. Preserve page/section references and distinguish direct quotation, paraphrase, inference, and uncertainty.
5. Search broadly, then gather evidence narrowly; record excluded sources and reasons.
6. Reconcile disagreements and retractions where relevant.
7. Generate a claim-to-source matrix and limitations.
8. Store caches/indexes outside distributable product packages unless licensing permits.

## Outputs

- Source registry.
- Extraction manifest.
- Evidence table.
- Answer-first report with citations.
- Uncertainty/contradiction log.
- Reproducibility notes and tool versions.
